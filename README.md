# VISIONSHOP
UI/UX design and interactive prototype for an e-commerce shopping application.
Vision Shop E-Commerce Application – Project Documentation
UI/UX Design and Interactive Prototype Project
1. Project Overview
KoraShop is a proposed online shopping application designed to provide users with a simple, clear, and user-friendly shopping experience. The application allows users to browse products, explore categories, view product details, add products to a shopping cart, complete checkout, and receive order confirmation.

3. Problem Statement
Many online shoppers, especially young people and students, face difficulties when searching for products, browsing different categories, comparing products, and completing purchases online. Some shopping platforms have complicated navigation, unclear product information, and difficult checkout processes.
KoraShop aims to provide a simple and user-friendly online shopping experience where users can easily search for products, browse categories, view product details, add items to their cart, and complete their orders through a straightforward checkout process.

7. User Flow
The user flow diagram illustrates how a customer moves through the KoraShop application. The main journey starts at Login, continues to Home, and allows the user to browse Categories or select a Product. The user can then add a product to the Shopping Cart, proceed to Checkout, and receive Order Confirmation.
Main flow: Login → Home → Product Details → Shopping Cart → Checkout → Order Confirmation
Alternative navigation: Home → Categories → Product Details

15. Accessibility Considerations
•	Use readable text sizes and clear typography.
•	Maintain sufficient contrast between text and backgrounds.
•	Use clear labels for buttons and navigation items.
•	Keep navigation consistent across screens.
•	Use simple and understandable wording for actions such as Add to Cart, Checkout, and Place Order.
•	Provide clear visual feedback and confirmation after important actions such as placing an order.

19. Challenges Encountered
During the design process, challenges included learning how to use Figma, organizing multiple screens, creating consistent high-fidelity designs, and connecting the screens using Figma Prototype interactions. The project also required careful organization of the design stages from wireframes to high-fidelity screens and the final interactive prototype.
20. Conclusion
KoraShop demonstrates the design process of an e-commerce application from initial planning and wireframes to high-fidelity interface design and interactive prototyping. The final prototype focuses on simple navigation and a clear shopping journey, helping users discover products and complete purchases efficiently.
